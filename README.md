# Оптимизација на соларно-батериски системи

Веб алатка која на македонски домаќинства и фирми им дава **објективна препорака**
за оптимална големина на соларна батерија — со реални цени, официјални EVN 2026
тарифи и математичка оптимизација.

**Maria Mitrikeska · 2026**

---

## Што прави

Внесуваш месечна EVN сметка и неколку параметри → за 60 секунди добиваш:

- колкава батерија е оптимална за твојот случај
- колку ќе заштедиш годишно
- за колку години се враќа инвестицијата (NPV, отплата)

## Како работи

```
1. ПОДАТОЦИ  →  2. ML ПРОГНОЗА  →  3. LP ОДЛУКА  →  4. ЕКОНОМИЈА  →  5. ПРЕПОРАКА
```

| Чекор | Фајл | Што прави |
|---|---|---|
| 1 | `podatoci.py` | PVGIS сончеви податоци + профил на потрошувачка |
| 2 | `ml_prognoza.py` | XGBoost прогнозира колку сонце ќе има утре |
| 3 | `lp_optimizacija.py` | PuLP + CBC наоѓаат најевтин план за батеријата |
| 4 | `presmetka.py` | Тестира сите батерии → заштеда, отплата, NPV |
| 5 | `api.py` + `index.html` | Flask сервер и веб интерфејс |

`config.py` ги содржи сите параметри — тарифи, цени, лимити.

## Поделба на улоги

**ML = ГАТАЧОТ** — само предвидува што ќе се случи, не одлучува ништо.

**LP = ПЛАНЕРОТ** — само одлучува што да се прави, не предвидува ништо.

## Машинско учење

XGBoost учи од 21.673 примери (30 месеци историја) да прогнозира соларна
продукција од 22 features: календарски, метеоролошки и историски.

**Резултат на тест** (6 месеци кои моделот никогаш не ги видел):

| Метрика | Вредност |
|---|---|
| MAE | 0.151 kW |
| R² | 0.897 |
| Подобрување vs наивна прогноза | **+34%** |

Да тренираш повторно:

```bash
python ml_prognoza.py
```

Детално објаснување со графикони: `ml_prognoza.ipynb`

## Оптимизација

За секој од 168 часа во една недела, LP одлучува колку батеријата да полни,
празни, купува и продава — со цел **минимална сметка**.

**Ограничувања:** енергетски биланс · SoC лимити (10-100%) · C-rate 0.5 ·
round-trip ефикасност 90%.

CBC solver-от **гарантира** дека ниту еден друг план не е поевтин.

За брзина се симулираат 4 сезонски недели × 52 наместо цела година
(грешка < 5%, време < 60 сек).

## Ограничувања

- Load профилот е синтетички — нема јавни smart-meter податоци во Македонија
- Прогнозата за облаци е историски измерена, не вистинска прогноза
- Не е вклучен degradation модел на батеријата
